# about

Jonathan Coppola's About page: resume, stage, and the table.
**https://coppolajonathan-lab.github.io/about/**

All of the content lives in [`data/profile.json`](data/profile.json). To change a job, add a show credit or edit a blurb, edit that file and push. No build step is needed.

Run locally: `python3 -m http.server 8000`, then open http://localhost:8000
